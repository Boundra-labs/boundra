# Boundra Boundary Spirit

UI reference pack for Boundra's selected mascot direction. These files are design references only and are not wired into the application.

## Assets

| File | Purpose |
| --- | --- |
| `01-character-model-sheet.png` | Front, three-quarter, side, and back proportion reference |
| `02-interaction-state-sheet.png` | Six full-body product states in reading order |
| `03-compact-ui-icon-set.png` | Six compact transparent UI status references |
| `04-landing-page-hero.png` | Transparent landing-page hero composition |

State order for assets 02 and 03, left-to-right and top-to-bottom:

1. Neutral / welcome
2. Thinking / evaluating
3. Success / confirmed
4. Warning / risk detected
5. Hold / waiting
6. Escalation / owner attention required

## Identity rules

- Compact teardrop body with one curved top tip.
- Large warm-ivory oval face.
- Exactly two vertical oval eyes; no mouth.
- Two stub arms and two stub feet.
- An open, segmented sage ring at waist height represents explicit authority boundaries.
- The ring is protective but never cage-like. It stays visible in normal full-body uses.
- Expressions come from pose, eye angle, and restrained status marks—not facial complexity.
- Keep the silhouette simple enough to recognize at small UI sizes.

## Usage guidance

- Use neutral for onboarding, empty states, and general assistance.
- Use thinking only while policy or mandate evaluation is active.
- Use success only after a state is genuinely confirmed; a broadcast transaction is not confirmation.
- Use warning for recoverable risk or degraded dependencies.
- Use hold when no action is needed and monitoring continues.
- Use escalation when owner intervention or renewed review is required.
- Do not make the mascot appear to approve authority on the owner's behalf.
- Avoid coins, trading charts, shields, robot parts, and speculative crypto imagery.
- Keep testnet and MockUSDC disclosures in the surrounding interface; do not place critical disclosures inside mascot artwork.

## Naming exploration

The neutral working label is **Boundary Spirit**. Short candidate names for later review:

- **Bori** — compact and loosely connected to Boundra.
- **Rin** — references the boundary ring.
- **Boun** — directly tied to the product name, but more literal.

Do not place a mascot name in product copy until the team selects one and checks naming availability.

## Generation briefs

All images were created with the built-in image-generation tool using the approved concept as the identity reference.

- **Model sheet:** preserve the approved character exactly and render aligned front, three-quarter, side, and back views on warm ivory.
- **State sheet:** preserve identity and render neutral, thinking, success, warning, hold, and escalation poses in a two-by-three grid.
- **Icon set:** simplify the same character into six compact bust icons on a genuinely transparent background.
- **Hero:** preserve identity and show the mascot guiding abstract intent, constraints, and evidence cards through its boundary ring on a transparent wide canvas.
