\section{Who does what}

\begin{stable}{@{}P{2.6cm}P{6.4cm}L@{}}
\headrow \thead{Part} & \thead{Does} & \thead{Never does}\\ \midrule
Owner's wallet & Signs sign-in messages and every owner transaction: create executor, set mandate, approve and fund, pause, resume, revoke, recover. & Hands its key to anyone.\\
Web app & Guides the owner, prepares the exact transactions, shows chain-confirmed state, forwards \code{/api/v1/*} to the API so the browser sees one origin. & Hold keys or secrets.\\
API & Sessions, intents and ACCE questions, mandate drafts and previews, dashboard and activity from confirmed state. & Sign transactions or move funds.\\
Worker & Watches vault risk, decides what the agent should do, and executes bounded operator transactions with the agent's own key. & Act outside a confirmed mandate, or for a mandate naming another agent.\\
Executor contract & Enforces the mandate on every operator call; pays withdrawals to the owner. & Accept arbitrary calls, recipients or upgrades.\\
\end{stable}

\begin{keypoint}[One origin]
The browser only ever talks to the web app's origin. Sessions use a first-party \code{\_\_Host-} cookie, and every state-changing request must carry that exact \code{Origin}. The web app's route handler forwards \code{/api/v1/*} to the API (in a public Compose deployment, Caddy routes it directly), so the cookie never crosses sites.
\end{keypoint}

\section{Repository layout}

The code is one pnpm workspace (Node.js 22.22, pnpm 10.32). Each team member owns parts of it.

\begin{btable}{@{}P{4.4cm}L@{}}
\headrow \thead{Path} & \thead{Contents}\\ \midrule\endhead
\code{contracts/} & Solidity contracts, Foundry tests and the deploy script (Person 1).\\
\code{packages/chain} & Generated ABIs, the deployment-manifest schema, \code{BoundraChainReader} and \code{prepareAction}.\\
\code{packages/shared} & Zod schemas, exact amount types, stable error codes.\\
\code{packages/database} & Prisma schema, migrations, client and the job queue.\\
\code{packages/acce} & The ACCE planner, vault selection and the mandate builder.\\
\code{packages/llm} & Optional language-model providers with validation and fallbacks.\\
\code{packages/sdk} & \code{@boundra/sdk}: owner API client and bounded operator.\\
\code{apps/api} & NestJS REST API with OpenAPI.\\
\code{apps/worker} & Chain boundary (\code{chain/}), decisions and jobs (\code{orchestration/}), stores (\code{persistence/}).\\
\code{apps/web} & Next.js owner app and landing page.\\
\code{apps/mcp} & MCP server for AI assistants.\\
\code{evaluation/} & B0–B3 benchmark runner and persona fixtures.\\
\code{deploy/}, \code{compose.yaml}, \code{render.yaml} & Deployment: Compose stack, Caddy, backups, manifests, Render.\\
\end{btable}
