\chapter{Data model}\label{ch:data}

PostgreSQL 17 through Prisma 7 (\code{packages/database/prisma/schema.prisma}). Migrations are applied as a release step (\code{pnpm db:migrate}) and never reset at start-up.

\begin{keypoint}[Exact numbers only]
Token amounts and block numbers are stored as \code{NUMERIC(78,0)}, exact to the full uint256 range; on the wire they are base-unit strings (MockUSDC has 6 decimals), never floating-point numbers. Addresses are stored lowercase and hashes as lowercase \code{0x} hex.
\end{keypoint}

\section{Concurrency rules}

\begin{itemize}
  \item Workflow changes and their follow-up jobs commit in one transaction; job keys make enqueueing idempotent.
  \item Jobs are claimed with \code{FOR UPDATE SKIP LOCKED} and a lease; a crashed worker's job is reclaimed.
  \item Signer and monitor work hold a row lease across RPC calls (never a database transaction); every write locks the lease row and checks its fencing token.
  \item Answers use optimistic concurrency on \code{Intent.version}; approvals compare-and-set on status and preview hash.
  \item Partial unique indexes enforce the invariants that matter most: one authorized mandate per executor, one open action per executor, one live attempt per executor action nonce.
\end{itemize}

\begin{note}[The database is not the source of truth]
PostgreSQL holds workflow and history. Authority, funding, positions and receipts are always re-read from the chain before the worker acts.
\end{note}
