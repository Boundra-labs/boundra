# ACCE evaluation handoff

- Person 2 owns `runner/` and `baselines/` (B0–B3).
- Person 3 owns persona fixtures and reports; Person 1 reviews labels.
- Freeze 20 development and 30 held-out personas before the final run.
- Hidden labels must not reach policy-generation prompts.
- Report actual denominators, refusals, failures and draft-vs-approved results.

No benchmark results or datasets are fabricated in this scaffold. See PRD §11 and task assignment §6 for the consent/evaluation protocol that must be implemented.
